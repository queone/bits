## Emotions and Relational States

A vocabulary for feelings, and for the states that hold between people, kept for other entries to point to. Feelings come in degrees, so the first table is a set of scales. The grouping in the second and third parts is my own. For the published models, including Paul Ekman's six basic emotions and a Berkeley study's 27 categories, see [emotion classification](https://en.wikipedia.org/wiki/Emotion_classification).

### Emotions by intensity

[Robert Plutchik](https://en.wikipedia.org/wiki/Robert_Plutchik) named eight primary emotions. "Like colors, primary emotions can be expressed at different intensities." Read the rows in pairs: each emotion is followed by its opposite.

| Mild | Basic | Intense |
|---|---|---|
| Serenity | Joy | Ecstasy |
| Pensiveness | Sadness | Grief |
| Acceptance | Trust | Admiration |
| Boredom | Disgust | Loathing |
| Apprehension | Fear | Terror |
| Annoyance | Anger | Rage |
| Distraction | Surprise | Amazement |
| Interest | Anticipation | Vigilance |

Desire has a scale of its own, under [Desire](desire.md).

### Other emotions

| Group | Emotions |
|---|---|
| Positive / Affectionate | Affection, love, respect, gratitude, fondness |
| Positive / Self-Oriented | Happiness, contentment, pride, relief, hope, confidence |
| Neutral / Complex | Indifference, curiosity, ambivalence, attachment |
| Motivational / Drive-Based | Frustration, longing |
| Arousal / Surprise-Based | Shock, confusion |
| Negative / Self-Oriented | Loneliness, anxiety, despair, helplessness, insecurity |
| Negative / Tense | Resentment, jealousy, envy, contempt, hatred, distrust, suspicion |
| Moral / Social | Pity, compassion, guilt, shame, forgiveness, disappointment |
| Power / Status-Related | Humiliation, status pride |
| Existential / Meaning-Based | Meaningfulness, emptiness, awe, existential fear, transcendence |

### Relational states

These are not emotions in the narrow sense. They are drives, or states that hold between people, and feelings travel with them.

| Group | States |
|---|---|
| Positive / Affectionate | Loyalty |
| Neutral / Complex | Dependence, obligation, familiarity |
| Motivational / Drive-Based | Ambition, determination, motivation |
| Power / Status-Related | Dominance, submission, empowerment |
| Interpersonal Boundary | Closeness, distance, rejection, inclusion, alienation |
